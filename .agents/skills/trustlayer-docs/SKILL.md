## 3. GST Pricing & Calculation Engine Rules

When computing document financial totals:

1. **Line Total**:  
   `Line Subtotal = Quantity × Unit Price`  
   `Line Discount = Line Subtotal × (Item Discount % / 100)`  
   `Line Taxable = Line Subtotal - Line Discount`  
   `Line Tax = Line Taxable × (Item Tax % / 100)`  
   `Line Total = Line Taxable + Line Tax`

2. **Subtotal & Global Discount**:  
   `Subtotal = Sum of all Line Subtotals`  
   `Taxable Amount = Subtotal - Global Discount`

3. **India GST Split**:  
   - **Intra-state** (Same State): Split Tax into `CGST (Half Rate)` and `SGST (Half Rate)`.  
   - **Inter-state** (Different State): Charge `IGST (Full Rate)`.  
   - **Exempt**: `0% Tax`.

4. **Grand Total**:  
   `Grand Total = Taxable Amount + CGST + SGST + IGST + Round Off`

## 4. Document Verification Protocol

Every document generated by TrustLayerDocs receives a cryptographic verification block:
- Format: `verify.trustlayerlabs.com/[DOCUMENT_ID]`
- Includes: Unique SHA-256 verification hash, issuer stamp, creation timestamp, and tamper-proof audit trail.
- Verification status must present a green verified badge: `"✓ VERIFIED DOCUMENT"`.

## 5. Quotation to Invoice Lifecycle

```text
Quotation (TLQ-2026-XXXX) 
   ──[ Sent ]──> 
Viewed 
   ──[ Client Signatures ]──> 
Accepted (Signed) 
   ──[ Convert ]──> 
Invoice (INV-2026-XXXX) 
   ──[ Payment ]──> 
Paid
```

- When converting a Quotation into an Invoice, copy all line items, deliverables, pricing, and client records.
- Set Invoice status to `DRAFT` or `SENT` and issue automatic invoice number sequence (`INV-YYYY-XXXX`).

## 6. Visual Hierarchy & UX Principles

1. **Level 1 Focus**: Document Type (`QUOTATION`/`INVOICE`), Document ID, Grand Total, Client Name.
2. **Level 2 Scope**: Items Table, Financial Breakdown, Deliverables, Payment Terms.
3. **Level 3 Context**: Terms & Conditions, Bank Details, QR Verification Code, E-Signature.
4. **Target Ergonomics**: A business user should be able to create and send a quote in **under 5 minutes**.
